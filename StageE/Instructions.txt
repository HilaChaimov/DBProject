הוראות הפעלה לאפליקציית שלב ה':

1. ודאו ששרת ה-PostgreSQL שלכם למעלה והרצתם את הסקריפטים של השלבים הקודמים.
2. בתוך התיקייה StageE, יש קובץ .env עם פרטי ההתחברות (PGHOST, PGDATABASE, PGUSER, PGPASSWORD, PGPORT). ודאו שהם תואמים למסד הנתונים שלכם.
3. התקינו את הספריות הנדרשות על ידי הפקודה:
   pip install -r requirements.txt
4. הפעילו את האפליקציה על ידי הפקודה:
   streamlit run app.py
5. הדפדפן יפתח אוטומטית ויציג את המערכת. משם ניתן לנווט בין כל המסכים דרך התפריט בצד שמאל.
